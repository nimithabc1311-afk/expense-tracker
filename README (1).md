# 💰 Expense Tracker Dashboard

A simple and clean **Expense Tracker** web app built using **HTML, CSS, and JavaScript**.

**Name: Nimitha BC**

---

## 📌 Features

- ➕ Add income and expense transactions
- 🗂️ Categorize spending (Food, Transport, Shopping, Bills, Health, etc.)
- 📊 Doughnut chart showing spending by category
- 💳 Summary cards for Total Income, Total Expenses, and Balance
- 🗑️ Delete individual transactions or clear all
- 💾 Data saved automatically using localStorage (persists on refresh)
- 📱 Responsive design — works on mobile too

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- [Chart.js](https://www.chartjs.org/) — for the doughnut chart

---

## 🚀 How to Run

1. Download or clone this repository
2. Open `index.html` in any browser
3. Start tracking your expenses!
